Behind the games

Privacy & Your Choices

What is saved on your device, when third-party services are used, and how to change your choices.

This page describes the rebuilt TheQuizRealm experience. Updated 2026-11-02.

Local game progress

The player profile uses browser local storage under QR_PROFILE to save your chosen name, XP, achievements, streak, and recent results. It is not automatically uploaded by the shared progress engine. Some older games also save their own settings locally. Clearing site data removes those local saves. You can export a progress backup from your profile.

Optional analytics

Analytics is off by default. If you choose Allow analytics, the site loads the existing Google Tag Manager container, GTM-ML3F7KLZ. Analytics can report page visits and game events to help improve the site. Advertising-related consent remains denied. You can reopen from the footer and select Essential only. The site respects a browser's Global Privacy Control signal by leaving analytics disabled.

The rebuilt shared scripts no longer create automatic Firebase visit logs or recurring session heartbeats. A Tag Manager container is separately configured by its owner; this source rebuild does not change the container's internal account settings.

Hosted group games

Hosting or joining a multiplayer room uses the existing Google Firebase project for game-room state, player names, answers, and scores. Guest authentication can be used for this function. Choose a nickname rather than a full real name. Other players in that room can see the name and score you submit. Public game rooms are not suitable for private information. Resetting a local profile does not delete room data held by the existing service.

Other network requests

The site is served through the existing GitHub Pages setup. Older game pages may request fonts, icon styles, or libraries from third-party CDNs. Hosted game QR codes use api.qrserver.com and contain the public joining URL. Those services receive normal connection information such as an IP address. Their own privacy policies apply to their processing.

Advertising

Advertising requests are disabled in the rebuilt site. A publisher verification meta tag and ads.txt remain so the existing publisher account can be reviewed. Enabling ads later requires the appropriate approved account and consent setup; the optional analytics choice is not a certified advertising consent platform.

Contact and controls

Sending an email uses your email provider and includes the details you choose to send. Do not send sensitive personal information. For questions about this site, use Contact & corrections. To remove local progress, use Reset this profile or your browser's site-data controls.
