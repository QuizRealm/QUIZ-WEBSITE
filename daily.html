How the Daily Ten works

The daily round draws ten distinct questions from a curated set with short answer explanations. Choose one answer for each question, then review the correct answer before moving on. At the end, you can revisit every question and copy your result to challenge a friend.

The question set changes at midnight UTC, so people in different time zones can compare the same challenge. Your first completion on each date is recorded; replaying the same daily set does not award another completion. Your play streak uses the local date on your device and increases when you finish a game on consecutive days.

Progress is stored in this browser. You can export a backup from your player profile. If you would rather choose a topic, try the game library instead.
